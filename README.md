# E181480 - SmartStay Hotel Booking System

SmartStay Hotel Booking System - Java OOP Project for Kingston University.
This system automates hotel booking operations including room management, guest registration, booking with 2-day advance rule, cancellation with 24-hour rule, and final bill calculation (Base + Extra + Discount + Tax - Advance).

### How to Run
1. Open Apache NetBeans IDE
2. Open Project -> Select the 8 Java files
3. Run E181480_Main.java (Main Class)
4. Follow CLI Menu: Admin Login / Guest Menu
5. BUILD SUCCESSFUL will be shown after execution
